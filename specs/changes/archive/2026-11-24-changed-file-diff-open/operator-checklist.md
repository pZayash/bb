# Оператор: ручная проверка

- [x] Клик по имени файла в списке изменённых (composer, uncommitted и
  committed секции): diff-таб открывается, список прокручен к этому
  файлу, его карточка развёрнута; соседние карточки остаются свёрнутыми
  при большом списке.
- [x] Действие строки «Open file diff»: файл открывается во вторичной
  панели в Monaco diff-режиме `split`, отображаются изменения, view
  стоит на первом изменении.
- [x] Переключение в `unified` в тулбаре Monaco: одноколоночный вид,
  отметки изменённых строк сохранены, навигация по изменениям работает.
- [x] Повторный клик того же действия при уже открытом табе: intent
  применяется заново (свежий `requestId`).
- [x] Удалённый файл: действие открывает preview по `HEAD`/merge-base
  без diff-режима; недиффируемый файл (added/untracked) — preview
  рабочего дерева.
