# Подсветка вхождений слова/выделения в diff и file view

## Проблема

При чтении диффа в сайдбаре (git-панель «All changes», timeline-блоки,
monaco diff tab) нет способа быстро увидеть все места, где фигурирует
идентификатор. В редакторе (Monaco) `occurrencesHighlight`/`selectionHighlight`
есть, в просмотре diff — нет: приходится эмулировать поиском
(см. скриншот постановки — выделение `ОсновнаяСтрана` через find).
`@pierre/diffs` готовой подсветки вхождений не предоставляет — только
колбэки `onTokenClick/onTokenEnter/onTokenLeave` и DOM-разметку токенов
`span[data-char]`.

## Цель

- Клик по слову в любом `BbDiff`/`BbSourceCode` подсвечивает все видимые
  вхождения целого слова (case-sensitive).
- Выделение текста подсвечивает все вхождения точной подстроки выделения
  (case-sensitive).
- Повторный клик по тому же слову, клик мимо или Esc снимают подсветку.
- Подсветка не мутирует DOM отрендеренного diff (CSS Custom Highlight API).

## Не-цели

- Подсветка в Monaco-редакторе (там есть своя).
- Навигация по вхождениям (prev/next, счётчик) — отдельный change.
- Подсветка в невидимых (невиртуализированных) строках за пределами
  отрендеренного окна pierre.
- Изменения в `@pierre/diffs` (не форкаем пакет).
- code-as-spec анкеры: для node-стека нет binding-дока и `PROJECT_PREFIX`,
  механизм не применяется к коду продукта bb.
