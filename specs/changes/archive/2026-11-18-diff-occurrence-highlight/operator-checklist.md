# Оператор: ручная проверка

Прогон в dev-приложении (`pnpm dev`), панель git «All changes»:

- [x] Клик по слову (идентификатор, кириллица) — все вхождения в файле
  подсвечены, на скролле новые строки тоже подсвечиваются.
- [x] Drag-выделение фрагмента — подсвечены все вхождения выделенного
  текста.
- [x] Повторный клик по тому же слову — подсветка снята.
- [x] Клик по пустому месту / Esc — подсветка снята.
- [x] Подсветка работает в unified и split режимах diff.
- [x] Подсветка работает в file view (BbSourceCode).
- [x] Существующие выделения строк (line selection, add-to-chat) не ломаются
  при клике по слову.
- [x] Две панели diff одновременно — подсветки не затирают друг друга.
- [x] Тёмная и светлая темы — подсветка читаема.
