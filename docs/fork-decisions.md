# Fork decisions (P2)

Product and merge-policy decisions for this Windows fork. They were taken on
2026-11-10 after the P0/P1 merge-cost work; revisit only with new evidence.

| Area                                                                         | Decision                                                                                                                                                    | Why                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DB delta (`environments.start_ref`, `threads.parent_notifications_muted_at`) | Keep both features.                                                                                                                                         | They are shipped product behavior (diff baseline, parent mute). Removing one does not remove the regenerated migration or the per-merge regeneration, and removing `start_ref` also breaks the `thread_start` diff base. `packages/db/src/migrate-parent-notifications-mute.fork.ts` keeps legacy databases safe. |
| `file-diff` / document export                                                | Keep fork-owned. Extract only cheap seams; do not delete.                                                                                                   | Shipped diff navigation, full-file diff, markdown preview, and export. An upstream PR stays a human decision.                                                                                                                                                                                                     |
| `threadRowMetadata`                                                          | Keep the 53-line `ThreadRow` patch for now.                                                                                                                 | The opt-in slot exists, but enabling metadata by default changes every user's sidebar and every plugin's row. The patch is small; revisit only with a product request for metadata-by-default.                                                                                                                    |
| `compaction-model`                                                           | Keep.                                                                                                                                                       | It is the only manual-compaction UI and the only way to pick a cheaper model for Pi compaction. Deletion would not remove `docs/configuration.md` conflicts and would require re-homing `thread.model`/`reasoningLevel`.                                                                                          |
| `log-noise` tag                                                              | Keep the CSS-retry fix; keep the log demotion for now.                                                                                                      | The tag mixes a functional plugin-style retry fix with cosmetic log levels. Deleting it wholesale would remove the fix; splitting it is not worth the churn yet.                                                                                                                                                  |
| Windows contract                                                             | Keep the broad supported contract: native Windows x64, `.ps1` hooks with Git Bash fallback, UNC project paths, terminal shell picker, protocol offset `+2`. | This is the fork's reason to exist. Upstream alpha parity would remove working scenarios.                                                                                                                                                                                                                         |
| Upstream PRs                                                                 | Do not prepare or open upstream pull requests as part of this work.                                                                                         | Only a human decides whether work goes to `get-bb/bb`; the fork keeps changes local.                                                                                                                                                                                                                              |
| `docs/api_to_audit.md`                                                       | Consolidate fork audit entries into one append-only block at the end, and regenerate the file at merge time.                                                | Fork sections currently sit in several upstream paragraphs; one block plus a resolver removes the 8-conflict seam.                                                                                                                                                                                                |
| `turbo.json`                                                                 | Regenerate from upstream plus `scripts/windows/turbo.fork.json` at merge time.                                                                              | Fork task and input additions no longer conflict with upstream edits.                                                                                                                                                                                                                                             |
| Tests                                                                        | Extract pure additions into `*.fork.test.*` only when the addition is a self-contained block; leave fixture-field insertions in place.                      | Moving non-separable additions would duplicate fragile setup without reducing conflicts.                                                                                                                                                                                                                          |
| Merge metric                                                                 | `conflicts`/`conflictCount` count raw merge conflicts only; generated artifacts are reported separately.                                                    | Keeps the conflict log comparable across merges.                                                                                                                                                                                                                                                                  |
